# 🔍 Port Scanner (Python)

A fast and simple multithreaded port scanner built using Python.

---

## 🚀 Features
- Scan IP address or domain
- Multithreaded (fast scanning)
- Detects open ports
- Basic service identification
- Saves results to file

---

## 🛠️ Requirements
- Python 3

---

## ▶️ How to Run

```bash
python3 src/scanner.py
